Ingresa con tu token de GitHub.

Solo las cuentas con permiso de edición en este repositorio pueden abrir el gestor y publicar cambios en la tienda.

¿Cómo obtengo mi token? (No llega al correo, se crea una vez en GitHub)
  1. Entra con tu cuenta de GitHub a Configuración de tokens ↗ .
  2. En Repository access, elige Only select repositories y selecciona Mundo-de-las-tenis.
  3. En Permissions → Repository permissions, pon Contents en Read and write.
  4. Pulsa Generate token, cópialo en un lugar seguro y pégalo arriba.
